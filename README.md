# Anuj Jain – 3D Portfolio 🚀

This repository contains the source code for **Anuj Jain’s 3D developer portfolio**, built with modern frontend, animation, and 3D tooling. It showcases my experience as a **full‑stack developer** with projects like **Finsight‑OCR**, **Inventory Management System**, and **CryptoDash**.

## Tech Stack 🧰

- **Frontend**: React, TypeScript, Vite, HTML, CSS
- **3D & Graphics**: Three.js, @react-three/fiber, @react-three/drei, WebGL
- **Animations**: GSAP, Framer‑style motion effects, custom scroll/hover FX
- **Tooling**: ESLint, Node.js, npm

## Sections Included 📚

- **Hero / Landing** – 3D character + intro with my name and role.
- **About** – Summary of my background (B.Tech AI & ML at Newton School of Technology, ADYPU, Pune).
- **What I Do** – Skills and focus areas in full‑stack and AI‑driven products.
- **Career** – Timeline including freelance work for Shri Gurukripa Trading Company and open‑source contributions.
- **Work** – Highlighted projects:
  - Finsight‑OCR (AI‑powered invoice analytics)
  - Inventory Management System (MERN SaaS for retail)
  - CryptoDash (real‑time crypto dashboard)
- **Tech Stack** – Interactive 3D bubbles of technologies I use.
- **Contact** – Email, phone, and social links.

## Getting Started 🏃‍♂️

```bash
git clone https://github.com/ighackerbot/3d_portfolio.git
cd 3d_portfolio
npm install
npm run dev
```

Then open the URL shown in your terminal (usually `http://localhost:5173`) in your browser.

## Notes on GSAP Plugins ⚙️

This project uses GSAP for animations. If you want to use **Club GreenSock** plugins in production, follow the official docs:  
`https://gsap.com/docs/v3/Installation/`

The current setup uses public/trial‑friendly configurations so you can clone and run it locally.
